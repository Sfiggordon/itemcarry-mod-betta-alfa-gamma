# Item Carry Mod (Fabric, Minecraft 1.20.1)

Мод делает три вещи:

1. **Выброшенные предметы никогда не исчезают.**
2. **Их нельзя подобрать обычным способом** (прошёл мимо — не подобрал). Подобрать можно только
   наведя прицел на предмет и нажав клавишу **R** (можно поменять в Настройки → Управление →
   категория "Item Carry Mod").
3. **Левый клик (удар) по выброшенному предмету** хватает его — он прикрепляется к камере, как в
   Teardown. Повторный левый клик — бросает предмет вперёд.

## Как собрать .jar через GitHub Actions (с телефона)

1. Создай новый репозиторий на GitHub (можно приватный).
2. Залей туда все файлы из этого архива, сохранив структуру папок как есть
   (важно, чтобы `.github/workflows/build.yml` остался по этому пути).
3. Открой вкладку **Actions** в репозитории — сборка запустится сама после заливки файлов
   (или нажми "Run workflow" вручную, если не запустилась).
4. Подожди 2-5 минут, зайди в завершённый workflow run, внизу будет **Artifacts** →
   `itemcarry-mod` — скачивай, там `.jar`.

## Как поставить мод на телефон / устройство

1. Нужен **Fabric Loader 0.15.x** для Minecraft **1.20.1** (через лаунчер типа PojavLauncher,
   FCL и т.п. — у них есть встроенная установка Fabric).
2. Нужен **Fabric API** (обычный мод, скачивается отдельно с Modrinth/CurseForge, версия под 1.20.1).
3. Кидаешь собранный `itemcarry-*.jar` в папку `mods` рядом с Fabric API.

## Структура проекта

```
build.gradle              — сборочный скрипт (Fabric Loom)
gradle.properties         — версии Minecraft/Fabric/Loader
settings.gradle           — настройки Gradle-репозиториев
src/main/java/...         — код мода
src/main/resources/...    — fabric.mod.json, mixins, переводы клавиш
.github/workflows/build.yml — автосборка .jar в облаке GitHub
```

## Если что-то не собралось

Открой лог упавшего шага в Actions — обычно проблема в версиях (например, если Fabric успел
выпустить новый loader/API и старый номер версии из `gradle.properties` уже не существует).
